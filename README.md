# 反诈剧情模拟 · 网页版

以真实诈骗话术为蓝本的情景互动反诈演练。纯静态网页，无需安装、无需构建，双击 `index.html` 即可打开，也可以直接部署到 GitHub Pages 生成公开链接。

## 一、项目简介

体验者以第一人称进入陌生来电与可疑信息的现场，在完整还原的剧情中做判断、做决定。每一次选择都会改变风险走向与最终结局，结束后给出复盘反馈，帮助体验者把「先核实、再行动」沉淀为习惯。

## 二、功能

- **分支叙事**：6 个案件，覆盖冒充客服、刷单返利、冒充公检法、婚恋交友、游戏交易、机票退改签等高发类型。
- **多结局**：每个案件 3 个结局（安全 / 警惕 / 危险），由你的选择路径决定。
- **限时决策**：部分关键决策带倒计时，超时会自动进入对应分支。
- **线索核验**：推进前需主动核实关键线索（物流、官方客服、110 等）。
- **风险指数**：随选择实时变化，安全判断降风险，轻信冒险升风险。
- **复盘反馈**：结局页给出风险指数、关键决策次数、线索核验项数、结局收集进度与行动建议。
- **案件库与进度**：显示每个案件的完成状态与结局收集情况。
- **记录回看**：已通关案件可查看最近一次完整记录。
- **本地存档**：进度、通关、结局收集保存在浏览器 `localStorage`，刷新不丢；换浏览器或清除站点数据会重新开始。
- **体验控制**：声音开关、全屏切换。

## 三、文件结构

```
ScamShield-Web/
├── index.html     页面结构与各屏（首页 / 案件库 / 剧情 / 结局）
├── styles.css     全部样式（深色沉浸风，含响应式）
├── data.js        剧本数据（6 个案件的节点、选项、结局）
├── app.js         剧情引擎（渲染、分支、风险、限时、线索、存档）
└── README.md      本说明
```

## 四、本地打开

直接双击 `index.html` 即可。四个文件在同一目录，浏览器用 `file://` 也能正常加载脚本与样式。

> 提示：如果双击后样式或脚本没生效，说明浏览器拦截了本地脚本，换用下面的本地服务器方式即可。

### 本地服务器（可选）

在项目目录下任选一种：

```bash
# Python 3
python -m http.server 8080
```

然后浏览器访问 <http://localhost:8080>。

## 五、部署到 GitHub Pages（生成公开链接）

1. 在 GitHub 新建一个 **Public（公开）仓库**，例如 `ScamShield-Web`。
2. 把本文件夹里的 4 个文件（`index.html`、`styles.css`、`data.js`、`app.js`）上传到仓库根目录。
3. 打开仓库 **Settings → Pages**。
4. **Source** 选择 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`，保存。
5. 等待 1–2 分钟，页面会给出链接：`https://<你的用户名>.github.io/ScamShield-Web/`。
6. 把链接发给任何人，任何设备浏览器打开即可体验。

> ⚠️ 仓库必须是 **Public**，GitHub Pages 才能对所有人公开访问；私有仓库需要付费账户才能发布。

## 六、如何新增案件

打开 `data.js`，在 `cases` 数组里追加一个对象即可，页面会自动收录：

```js
{
  id: "case-demo",
  icon: "🧪",
  type: "案件类型",
  title: "案件标题",
  desc: "一句话简介",
  endingsTotal: 3,
  start: "n1",
  nodes: {
    n1: { type: "dialog", speaker: "来电", text: "……", next: "n2" },
    n2: { type: "choice", prompt: "……", options: [
      { text: "……", next: "c1", risk: -10, tag: "谨慎", tone: "ok" },
      { text: "……", next: "e3", risk: 30, tag: "危险", tone: "bad" }
    ]},
    c1: { type: "clue", action: "你去核实……", clue: "【官方】……", ok: "……", next: "e1" },
    e1: { type: "ending", rating: "安全", title: "……", desc: "……", advice: ["……", "……"] }
  }
}
```

节点类型：

| 类型 | 字段 | 说明 |
| --- | --- | --- |
| `dialog` | `speaker` `text` `next` | 一句对白，点「继续」推进 |
| `choice` | `prompt` `options[]` (`timeLimit` `timeoutNext` `timeoutRisk` 可选) | 选择分支，可设倒计时 |
| `clue` | `action` `clue` `ok` `next` | 线索核验，核验一次 +1 |
| `ending` | `rating` `title` `desc` `advice[]` | 结局页内容 |

`tone` 可选 `ok` / `warn` / `bad` / `neutral`，决定选项角标颜色。

## 七、说明

本项目为反诈宣传教育用途的演示内容，剧情与话术均为模拟，请勿用于任何违法用途。真实遭遇诈骗，请立即拨打 **110** 或 **96110**（国家反诈中心）。
